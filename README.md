# Agente BimBam Buy

Projeto desenvolvido para o Challenge Alura Agente, da formação ONE AI For Tech.

O agente responde perguntas sobre reembolsos e devoluções usando exclusivamente a política oficial fictícia da BimBam Buy. O projeto emprega RAG (Retrieval-Augmented Generation), possui uma interface web simples e será publicado na Oracle Cloud Infrastructure.

> Documentação em construção. As instruções completas, exemplos e evidências do deploy serão adicionados durante o desenvolvimento.
